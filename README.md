# SkillRush — Telegram Mini App prototype

## Запуск локально
Откройте `index.html` в современном браузере. Для тестирования внутри Telegram Mini App сайт нужно разместить на HTTPS.

## Подключение к Telegram
1. Создайте бота через @BotFather.
2. Разместите `index.html` на HTTPS-хостинге (например, Vercel или Netlify).
3. Настройте Mini App в BotFather и укажите URL сайта.

## Важно
Это клиентский прототип. Прогресс хранится в localStorage текущего браузера и не синхронизируется между устройствами. Баланс и результаты можно изменить через инструменты браузера. Перед публичным запуском добавьте backend, проверку Telegram WebApp initData на сервере и серверное начисление наград. В текущей версии нет настоящего PvP и общей таблицы лидеров.
